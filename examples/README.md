# MX examples

A real folder to test the folder picker and the editor. In MX:

1. Click the folder key next to `mx-workspace` in the Files rail, or choose
   `File ▸ Open workspace folder…`.
2. Pick this `examples/` folder.
3. Open a script and press `Ctrl/Cmd+Enter` (cell) or `Shift+Enter` (line).

The folder is read/write in Chrome and Edge; Firefox and Safari use the read-only folder input.

| File | What it shows |
| --- | --- |
| `subplots.jl` | 2 × 2 lines, surface and heat |
| `subplot-scatter.jl` | 2 × 2 lines, scatter, surface and heat |
| `lines.jl` | 1 × 2 lines |
| `surfaces.jl` | 1 × 2 surface and heat |
| `lorenz.jl` | a Lorenz RK4 loop, then `plot` |
| `state_space.jl` | A, B, C, D, x0 for Paperboat |
| `export.jl` | savefig, writematrix, save |
| `surface.jl` | the peaks surface |
| `peaks.jl` | a height field |
